# Book Library Django App

A full-stack Book Library application built with Python and Django.

## Features
- Full CRUD functionality (Create, Read, Update, Delete) for books.
- Filter books by read status and author name.
- Responsive UI with custom CSS.
- Secure forms with CSRF protection and Post/Redirect/Get (PRG) pattern.
- Django template inheritance using a `base.html`.

## Technologies Used
- Python
- Django
- SQLite
- HTML5 / CSS3
